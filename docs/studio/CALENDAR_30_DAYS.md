## Gate dependencies
- Day 03–06 cannot promote new Catpat art before Day 02 identity lock.
- Day 09 and Day 26 cannot finalize hazards before Day 07 measurements.
- Day 13–17 UI must use the image-authored system; code-only placeholder visuals cannot be accepted.
- Day 20–23 companions require each character’s book-faithful identity lock before animation production.
- Day 25 comic final art depends on Day 18 grammar and Day 19–23 portrait packages.
- Day 29 cannot pass while any P0/P1 defect remains.

## Daily evidence package
Every closed gate must have:
1. canonical binary assets in GitHub,
2. manifest changes,
3. runtime/source integration where applicable,
4. QA evidence/result,
5. daily report,
6. exact commit SHA(s),
7. open-risk list for the next gate.

## Milestone interpretation
Day 30 is not “the whole franchise is finished.” It is the first professional production milestone: Chapter 1 polished, art/UI/animation/comic pipelines proven, and the project structured so later chapters can scale without improvising a new style or workflow.
